# Tool Page

브라우저에서 바로 사용하는 픽셀 스타일 파일 변환 툴 허브입니다.
이미지 변환부터 PDF/PPTX 생성까지 설치 없이 처리할 수 있도록 정적 페이지로 구성되어 있습니다.

## 포함 기능

- Image Conveter: JPG/PNG/WEBP/SVG/TIFF 입력, JPG/PNG/WEBP 출력, 공통/파일별 형식 지정
- Images to GIF
- Images to PDF
- Images to PPTX
- PDF to Images
- PPT to Images

## 주요 특징

- 검정 배경과 `#FF00FF` 포인트 컬러를 사용한 픽셀 아트 도트 스타일
- PDF/PPTX 생성 순서를 카드 드래그 방식으로 조정
- 변환 결과 개별 다운로드 및 ZIP/문서 다운로드 지원
- GitHub Pages로 바로 배포 가능한 정적 파일 구조
