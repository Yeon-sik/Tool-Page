# Tool Page | 서버 업로드 없이 브라우저에서 처리하는 파일 도구 허브

## 1. 30초 요약

- **문제**: 이미지·문서·오디오의 간단한 변환에도 서로 다른 웹 서비스나 데스크톱 프로그램을 오가야 하며, 민감할 수 있는 원본을 외부 서버에 올려야 하는 경우가 많습니다.
- **해결**: 파일 선택부터 변환, 미리보기, ZIP 또는 개별 파일 다운로드까지 브라우저 안에서 끝나는 정적 도구 허브를 구성했습니다.
- **핵심 결과**: 6개 도구 진입점에서 이미지 형식 변환, GIF 생성, PDF/PPTX 양방향 작업, MP3 구간 편집, 단일·일괄 이미지 편집을 제공합니다.
- **기술적 차별점**: 공통 파일 큐·검증·취소·설정·다운로드 흐름은 공유하고, 형식별 변환 로직은 독립 모듈로 분리했습니다.

## 2. 문제와 해결

| 사용자 문제 | 해결 방식 | 사용자에게 주는 가치 |
| --- | --- | --- |
| 작업마다 다른 도구를 찾아 이동해야 함 | 검색·카테고리 필터·최근 사용 도구가 있는 단일 허브 | 반복 작업 진입 시간과 화면 전환 감소 |
| 원본 파일을 외부 서비스에 업로드하기 부담스러움 | File API, Canvas, Web Audio API와 저장소 내 라이브러리로 로컬 처리 | 서버 업로드 단계를 제거하고 네트워크 의존성 축소 |
| 여러 파일의 순서·설정·결과 이름을 관리하기 어려움 | 정렬, 드래그/키보드 재배치, 설정 복원, 충돌 없는 파일명, ZIP 출력 | 일괄 작업 중 덮어쓰기와 순서 실수 감소 |
| 큰 파일이나 지원하지 않는 형식이 브라우저를 멈출 수 있음 | 파일 수·용량·픽셀·페이지·슬라이드 한도와 명시적 실패 처리 | 브라우저 자원 고갈 위험을 조기에 차단 |

## 4. 핵심 사용자 흐름

```text
홈에서 도구 검색 또는 선택
  -> 원본 파일 선택/드롭
  -> 파일·용량·형식 안전 한도 검증
  -> 순서와 출력 설정 조정
  -> 브라우저 메모리에서 변환
  -> 미리보기 확인
  -> 개별 파일 또는 ZIP/PDF/PPTX 다운로드
```

입력 원본과 결과 Blob은 브라우저 런타임에서 다룹니다. `localStorage`에는 최근 사용 도구와 변환 설정 같은 작은 UI 상태만 저장하며, 원본 파일 자체를 영구 저장하는 구조는 아닙니다.

## 5. 핵심 기술적 판단

### 공통 흐름과 형식별 로직을 분리

- `app.js`가 파일 큐, 예산 검증, 정렬, 설정, 취소, 다운로드와 파일명 충돌 방지를 담당합니다.
- `scripts/converter-*.js`와 `scripts/editor-*.js`는 각 형식의 파싱·렌더링·인코딩 책임만 가집니다.
- 단일 이미지 편집과 일괄 크기 조정은 상태와 UX가 달라 별도 모듈로 유지합니다.

이 구조는 프레임워크나 서버를 추가하지 않고도 공통 동작의 중복을 줄이고, 형식별 실패를 좁은 범위에서 추적하기 위한 선택입니다.

### 브라우저 한계를 제품 규칙으로 명시

- 공통 변환은 최대 100개, 파일당 120MB, 전체 250MB로 제한합니다.
- PDF 이미지 출력은 최대 120페이지와 Canvas 16,384px/8천만 픽셀 한도를 적용합니다.
- PPTX 이미지 출력은 최대 100슬라이드이며, 지원하지 않는 요소가 있으면 조용히 누락하지 않고 중단합니다.
- 일괄 이미지 편집은 최대 50장, 한 변 8,192px, 전체 출력 1억 5천만 픽셀을 넘지 못하게 합니다.

## 7. 현재 한계와 다음 단계

- **현재 한계**: PPTX 이미지 변환은 PowerPoint 렌더러가 아니므로 표, 차트, SmartArt, 연결선, 미디어 등은 지원 범위 밖입니다.
- **현재 한계**: 브라우저별 자동화는 Chromium과 WebKit을 다루지만 Firefox, 실제 모바일 기기, 저메모리 환경은 검증하지 않았습니다.
- **현재 한계**: 서버 업로드가 없다는 구조적 사실과 결과 파일의 완전한 정확성은 별개입니다. 중요한 PDF/PPTX 결과는 원본과 대조해야 합니다.
- **다음 단일 단계**: 대표 실파일 fixture 묶음과 예상 출력 스냅샷을 추가해 형식 호환성 회귀를 자동 검증합니다.
- **의도적으로 하지 않는 것**: 사용자 계정, 클라우드 저장, 서버 변환 큐는 현재의 정적·로컬 처리 범위를 복잡하게 하므로 우선순위에서 제외합니다.
