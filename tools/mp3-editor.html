EDITOR 07

MP3 Editor

MP3 파일을 브라우저 안에서 바로 불러와 파형을 보고 자르기, 배속 미리 듣기, 구간 분할과 MP3 저장까지 한 번에 처리합니다.

UPLOAD

편집할 MP3 업로드

파형을 확인하고 구간을 자른 뒤 필요한 부분만 세그먼트로 나누어 다시 MP3로 저장할 수 있습니다.

오디오는 브라우저 안에서 로컬로 처리됩니다. 편집 라이브러리도 이 사이트에 포함되어 있어 별도 CDN 연결이 필요하지 않습니다. 최대 파일 크기는 150MB입니다.

여기에 MP3 파일을 끌어놓거나 클릭, Enter, Space로 파일을 선택하세요.

MP3 파일은 브라우저 안에서만 처리됩니다. 파일을 올리면 파형을 보고 재생 위치와 선택 구간을 바로 조정할 수 있습니다.

No file loaded 0.00s / 0 KB 선택 구간 0.00s

파형 포커스 후 좌우 화살표는 1초, Shift+좌우 화살표는 5초 이동합니다. Home/End는 처음과 끝으로 이동하고, Space는 재생 또는 일시정지입니다.
