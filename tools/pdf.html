PDF로 묶을 이미지 업로드

파일 카드를 잡고 원하는 위치로 드래그하세요. 현재 목록 순서가 그대로 PDF 페이지 순서가 됩니다.

처리 방식: 파일 내용은 서버로 업로드하지 않고 현재 브라우저에서 PDF로 묶습니다. PDF 생성 라이브러리도 사이트에 포함되어 있습니다.

UPLOAD

이미지로 바꿀 PDF 업로드

PNG, JPG, WEBP 중 원하는 출력 형식을 고른 뒤 PDF 페이지를 이미지 파일로 변환합니다.

처리 방식: 파일 내용은 서버로 업로드하지 않고 현재 브라우저에서 렌더링합니다. 암호화된 PDF는 지원하지 않으며, PDF 렌더링과 ZIP 생성 라이브러리도 사이트에 포함되어 있습니다. 한 번에 최대 120페이지까지 변환합니다.
